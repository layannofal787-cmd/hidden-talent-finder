# Hidden Talent Finder

AI-powered platform for students and graduates.

## Problem
Many students and graduates do not know which skills are required in the job market.

## Solution
Our platform uses AI to analyze skills, recommend courses, verify learning through assessments, and connect users with suitable companies.

## Features
- AI Skill Analysis
- Personalized Course Recommendations
- Skill Verification
- Smart CV Builder
- Job Matching

## Tools Used
- Figma
- Canva
- GitHub

## Prototype
Designed using Figma.

## Future Vision
Integration with LinkedIn and real hiring systems.
